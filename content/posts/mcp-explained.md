## 这是什么
Model Context Protocol（MCP）是一套开放协议，用于连接 AI 应用与外部数据、工具。本文是协议背景资料整理，不是即时新闻。

## 用博客更新理解它
博客的 MCP 服务可以暴露列出文章、读取内容、保存文章和构建站点等工具。AI 客户端通过协议发现工具，并在权限允许的范围内调用它们。

## 静态网站如何配合
GitHub Pages 托管构建后的 HTML、CSS 和 JavaScript。MCP 服务运行在本地或单独的服务器上，将内容写入仓库；GitHub Actions 负责构建和发布。
